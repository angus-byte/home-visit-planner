      What columns can I import?

      Any spreadsheet with a header row. Column names are matched loosely, so "Patient name", "Child" or "Client" all work for the name.

      • Name (or First name + Last name)
      • Address (Suburb and Postcode columns are added on if separate)
      • Phone, Email, Parent/Guardian, Notes (optional)
      • Visit length in minutes, e.g. 45 (defaults to 60)
      • Days the family is available, e.g. "Mon, Wed" (blank = any day)
      • Zone (optional), e.g. "Zone 1" or "North", so you can plan one zone per day
      • Date and Time of a booking (optional). Rows with a date are added to that day in Plan a day. In Plan a day, "Import day from file" takes only the rows for the day you picked, and rows without an address are matched to clients already in your list by name.

      From Cliniko: a Cliniko patient export (Settings, Data exports, Patients) imports as is: Address 1 to 3, City, State and Post code are joined into one address.

          Import from Cliniko

          Pulls patient names, addresses, phone numbers and emails straight from Cliniko. Clinical notes are never fetched. Your API key is used only for this import and isn't saved unless you tick the box.

          Browsers can't call Cliniko directly, so the import goes through your own small connection link. Setup steps are in the app's GitHub repo (cliniko-proxy folder).
